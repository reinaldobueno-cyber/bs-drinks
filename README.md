# B.S Drinks — Experiência de Orçamento

Site de coquetelaria de experiência.

## URLs
- Site: https://bs-drinks.netlify.app
- Admin: https://bs-drinks.netlify.app/admin

## Variáveis de ambiente (Netlify → Site settings → Environment variables)
- `ADMIN_PASSWORD` — senha de acesso ao /admin
- `NETLIFY_AUTH_TOKEN` — Personal Access Token (User settings → Applications) com permissão de leitura de forms
- `SITE_ID` (opcional) — ID do site

## Deploy
Conectado ao repositório GitHub. Push na branch `main` dispara build automático.
